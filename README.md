
# Movie Discovery App

A modern, responsive movie discovery web application built with react.js, Tailwind CSS, and TMDb API integration. Features a minimalist UI focused on high-impact typography, spacious layouts, and smooth micro-interactions.

---

## Features

* **Featured Hero Showcase**: Dynamic banner showcasing trending movies with instant trailer previews.
* **Filter & Search**: Real-time multi-category filtering (Genre, Release Year, Rating, Popularity).
* **Infinite Scroll & Lazy Loading**: Optimally fetched media grids powered by Next.js Server Components and dynamic routing.
* **Detailed Movie Pages**: Comprehensive overview including cast details, budget, runtime, similar recommendations, and full trailer overlays.
* **Responsive Layouts**: Designed mobile-first using Tailwind CSS for seamless viewing across screens.

---

## Tech Stack

* **Framework**: [React.js](https://reactjs.org/) (App Router)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Deployment**: [Vercel](https://vercel.com/)

## Getting Started

### Prerequisites

Ensure you have Node.js 18.x or later installed

### Installation

1. **cd movie app**
```bash
cd movie-app

```


2. **Install dependencies**
```bash
npm install
# or
pnpm install
# or
yarn install

```


```


3. **Run the development server**
```bash
npm run dev

```



Open [http://localhost:5173](http://localhost:5173) in your browser to see the result.
